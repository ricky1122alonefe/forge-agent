配置 LLM API Key

关闭 Agent Mock 或使用 LLM 规划时需要 Key。Key 加密存入本地数据库，不会写入 Agent YAML 或项目 .env。

安全说明

  • 存储位置：~/.forge-agent/secrets/llm_keys.db（加密，按租户/项目隔离）
  • 不会出现在 agents/*.yaml 或可被 git 提交的项目文件里
  • 配置一次后重启服务仍有效；所有 Agent 试跑 / LLM 规划自动使用
  • Mock 模式 Agent 无需 Key，可先跳过
